> 확정일: 2026-02-13
> 최종 수정: 2026-02-13
> 상태: 진행 중

---

## 사업 컨셉

**포지셔닝**: 데크 설계부터 시공까지, 올인원 플랫폼

**비즈니스 모델**:
- B2C: 일반 사용자/시공업자가 직접 시뮬레이터 사용
- B2B: 자재 제조사/유통사에 화이트라벨 라이선스 납품

**핵심 가치 제안**:
- 1차 후크: "비용을 줄여드립니다" (스마트 자재 추천으로 평균 18% 절감)
- 2차 후크: "3분이면 끝납니다" (3D 설계 + 자동 견적)
- 근거: 자재 조합별 TCO(총소유비용) 비교
- 증거: 절감 사례 + 고객 후기

**타겟 사용자**:
1. 데크 시공업체 (입찰 + 설계 도구)
2. 인테리어/건축 디자이너 (설계 + 자재 비교)
3. 주택 소유자 (견적 확인 + 자재 선택)
4. 자재 제조사/유통사 (화이트라벨 도입)

## 페이지별 상세 설계

### 1. 홈페이지 (`/`)

```
[Hero]
  제목: "데크 비용, 평균 18% 절감합니다"
  부제: AI가 최적의 자재 조합을 찾아 불필요한 비용을 줄이고
       3D 설계부터 견적까지 3분이면 끝납니다
  CTA: [무료로 시작하기] [절감 사례 보기]
  비주얼: 시뮬레이터 스크린샷/GIF

[신뢰 지표]
  평균 절감율 18% / 절감 총액 N억 / 설계 N건 / 자재 100+종

[핵심 기능 3개]
  ① 3D 실시간 설계
  ② 자동 견적 산출
  ③ 도면·자재 리스트 내보내기

[자재 쇼케이스]
  목재 / 합성목 / 알루미늄 탭 전환 (현재 컴포넌트 활용)
  → "자재 가이드 더보기" 링크

[시공 사례 하이라이트]
  최신 3개 사례 카드 (사진 + 면적 + 자재 + 비용 + 절감율)
  → "시공 사례 더보기" 링크

[절감 사례]
  "이렇게 절감했습니다"
  2~3개 사례 (원래 견적 → 시뮬레이터 추천 → 절감액/절감율)
  CTA: [내 프로젝트 절감액 확인하기]

[고객 후기]
  현재 Testimonial 컴포넌트 유지

[입찰 정보 미리보기]
  "지금 N건의 데크 공사 입찰 진행 중"
  최신 3건 카드 + "전체 보기" 링크

[CTA]
  "지금 바로 시작하세요"
  [무료로 시작하기]
```

### 2. 시뮬레이터 (`/simulator`)

> `/app` + `/features` + `/pricing` + `/gallery` 통합

```
[Hero]
  제목: "드래그 한 번으로 데크가 완성됩니다"
  CTA: [무료로 시작하기] [데모 영상]
  비주얼: 시뮬레이터 실제 화면 임베드 또는 영상

[기능 상세]
  ① 3D 실시간 설계
     스크린샷 + "공간 크기 입력 → 자재 배치 → 완성"
  ② 100+ 자재 라이브러리
     스크린샷 + "실제 텍스처로 미리 확인"
  ③ 자동 견적 산출
     스크린샷 + "자재 수량, 예상 비용 실시간 계산"
  ④ 도면 내보내기
     스크린샷 + "PDF 도면 + 자재 리스트 다운로드"
  ⑤ 스마트 자재 추천
     스크린샷 + "같은 설계, 다른 가격"
     - 자재 조합별 비용 비교
     - 내구성·유지비 포함 총소유비용(TCO) 계산
     - "이 자재로 바꾸면 ₩240만 절감" 안내

[사용 흐름]
  Step 1: 공간 입력
  Step 2: 자재 선택
  Step 3: 견적 확인 & 내보내기

[갤러리]
  시뮬레이터로 만든 설계 예시 그리드

[가격]
  Free / Pro / Enterprise 카드
  Enterprise → "파트너 문의" 링크 (/partner)

[CTA]
  [무료로 시작하기]
```

### 3. 자재 가이드 (`/materials`)

> 중립적 정보 허브. SEO 핵심 페이지.

```
[Hero]
  제목: "데크 자재, 뭐가 다를까?"
  부제: 목재·합성목·알루미늄 완벽 비교

[자재 비교 테이블]
  | 항목        | 목재     | 합성목    | 알루미늄  |
  | 시공 가격   | ₩5~12만  | ₩8~15만   | ₩12~20만  |
  | 내구성      | ★★★     | ★★★★     | ★★★★★    |
  | 유지보수    | 매년     | 거의없음   | 없음      |
  | 수명        | 10~15년  | 20~25년   | 30년+     |
  | 10년 총비용 | ₩15~25만 | ₩9~16만   | ₩12~20만  |
  | 비용 효율   | ★★★     | ★★★★★   | ★★★★     |

  CTA: [시뮬레이터에서 비교해보기]

[자재 카테고리별 상세]
  📂 천연 목재
     서부 레드시더 / 이페 하드우드 등
     특징, 장단점, 적용 사례, 가격대

  📂 합성목재 (WPC)
     트렉스 / 한솔홈데코 등
     특징, 장단점, 적용 사례, 가격대

  📂 알루미늄
     퍼포레이티드 / 루버형 등
     특징, 장단점, 적용 사례, 가격대

[자재 선택 가이드]
  용도별 추천:
  - 주택 베란다 → 합성목 추천
  - 상업 시설 → 알루미늄 추천
  - 자연 친화 → 천연 목재 추천

[CTA]
  "자재를 3D로 직접 비교해보세요"
  [시뮬레이터 시작하기]
```

**SEO 타겟 키워드**: "합성목재 가격", "데크 자재 비교", "WPC 데크 장단점", "목재 데크 종류"

### 4. 시공 사례 (`/cases`)

```
[Hero]
  제목: "실제 시공된 데크를 확인하세요"
  부제: 설계부터 완공까지, 자재·비용·면적

[필터 바]
  [전체] [주거] [상업] [공공]  자재: [전체 ▾]

[사례 카드 그리드]
  각 카드: 사진 / 위치 / 자재 / 면적 / 비용 / 절감율
  기존 8개 케이스 활용

[CTA]
  "내 공간도 이렇게 만들어보세요"
  [시뮬레이터로 설계하기]
```

사례 상세 페이지 (`/cases/[slug]`):
- 갤러리 사진
- 자재 선택 이유
- Before/After 비용 비교
- 시공 기간, 면적, 위치

### 5. 입찰정보 (`/bids`) ✅ 완료

> 현재 구조 유지 + 2가지 추가 → **구현 완료 (2026-02-13)**

```
[기존 구조 전체 유지] ✅
  Hero / 통계 바 / 검색 필터 / 입찰 카드 / 낙찰 결과

[추가 ①: 시뮬레이터 연결 배너] ✅
  "입찰 준비에 시뮬레이터를 활용하세요"
  "3D 설계 + 자동 견적으로 제안서 퀄리티 ↑"
  [시뮬레이터로 설계하기]
  - 3개 기능 체크리스트 포함
  - 3D 시뮬레이터 목업 비주얼
  - 모바일에서 비주얼 숨김 처리

[추가 ②: 이메일 알림 구독] ✅
  "새 입찰 공고를 이메일로 받아보세요"
  [이메일 입력] [구독]
  → 리드 수집 → 향후 프리미엄 알림 서비스로 확장 가능
  - 로딩 스피너 + 성공 메시지 UX
  - 향후 실제 API 연결 필요 (현재 목업)

[추가 구현사항]
  - 입찰 링크 개선: detail_url 유무에 따라 외부 링크/텍스트 분기 처리
  - 외부 링크 아이콘(↗) 추가로 클릭 가능 여부 시각적 구분
  - CSS 디자인 토큰 정리: fallback 값 제거, 시멘틱 변수 통일
  - 헤더 네비게이션에 "입찰정보" 링크 추가 (데스크톱 + 모바일)
  - Edge Function: lofin 소스에 detail_url 생성 로직 추가
```

### 6. 블로그 (`/blog`)

변경 없음. 기존 구조 유지.

콘텐츠 방향:
- 자재 비교 ("합성목 vs 천연목 총비용 비교")
- 시공 가이드 ("데크 시공 시 실수하기 쉬운 5가지")
- 절감 팁 ("데크 비용 20% 줄이는 자재 선택법")
- 시뮬레이터 활용법

### 7. 파트너 (`/partner`)

> B2B 화이트라벨 전용. 자재 제조사 의사결정자 대상.

```
[Hero]
  제목: "귀사 브랜드로 3D 시뮬레이터를 제공하세요"
  부제: 고객 체험 → 자재 선택 → 매출 전환
  CTA: [도입 문의하기] [데모 요청]

[왜 화이트라벨인가]
  ① 고객 체류 시간 3배 증가
     "자사 홈페이지에 시뮬레이터 임베드"
  ② 자재 샘플 요청 40% 증가
     "직접 배치해본 고객이 구매 전환 높음"
  ③ 개발 비용 제로
     "자체 개발 대비 90% 비용 절감"

[화이트라벨 적용 예시]
  목업 이미지: 자재업체 브랜드가 적용된 시뮬레이터 화면
  커스터마이징 범위:
  - 로고·브랜드 컬러
  - 자사 자재만 노출
  - 커스텀 도메인
  - 견적 연동 (자사 가격표 적용)

[도입 프로세스]
  문의 → 데모 → 커스터마이징 → 런칭 (2주)

[CTA]
  [도입 문의하기]
  또는 전화 상담
```

**톤**: B2C 페이지보다 절제되고 비즈니스적. 숫자와 ROI 중심.

## 구현 우선순위

| 순위 | 작업 | 상태 | 이유 |
|------|------|------|------|
| 1 | 홈페이지 리뉴얼 | 대기 | 첫인상, 가치 제안 변경 |
| 2 | 시뮬레이터 페이지 | 대기 | 핵심 제품 페이지, 4개 통합 |
| 3 | 자재 가이드 | 대기 | SEO 유입 핵심, 콘텐츠 이미 있음 |
| 4 | 시공 사례 | 대기 | 콘텐츠 이미 있음, 카드 UI만 필요 |
| 5 | 입찰정보 개선 | ✅ 완료 | 배너 + 구독 폼 + 링크 개선 + 네비 추가 |
| 6 | 파트너 페이지 | 대기 | B2B는 시뮬레이터 출시 후 본격화 |
| 7 | 네비게이션 변경 | 대기 | 페이지 완성 후 한번에 교체 |
| 8 | 기존 페이지 삭제/리다이렉트 | 대기 | features, pricing, gallery → simulator 리다이렉트 |
