# 데크센터 (deckctr.com) 사이트 구조 및 콘텐츠 명세

## 사이트 정체성

**데크센터**는 데크 자재(천연목, 합성목, 알루미늄) 공급업체의 마케팅 웹사이트입니다.
핵심 서비스는 **3D 데크 설계 시뮬레이터**이며, 부가 서비스로 **공공 입찰정보 포털**을 운영합니다.

**타겟 고객:**
- B2B: 시공업체, 인테리어 디자이너, 주택개발사
- B2C: 데크 설치를 원하는 개인 (주택, 빌라, 테라스)

### 11. 입찰정보 `/bids` ★신규

시공업자를 위한 공공 입찰정보 포털. Supabase DB에서 실시간 데이터를 가져옴.

**데이터 소스:** 나라장터(G2B), K-APT, 지방재정365(LOFIN)

**현재 보유 데이터:**
- 입찰 공고 49건 (진행중 4, 마감 45)
- 낙찰 결과 60건
- 수주 업체 54개
- 총 추정가 약 19.4억원

**페이지 구성:**

1. **통계 대시보드** (4개 숫자 카드)
   - 진행중 공고 수
   - 완료된 계약 수
   - 낙찰 결과 수
   - 총 추정가

2. **필터 바**
   - 텍스트 검색 (공사명, 기관명)
   - 출처 탭 (전체 / K-APT / 지자체)
   - 지역 드롭다운 (경기, 경남, 부산 등)
   - 상태 필터 (전체 / 진행중 / 마감)
   - "총 N건의 공고" 카운트

3. **입찰 카드 그리드** (메인 콘텐츠)
   각 카드 정보:
   - 출처 뱃지 (나라장터/K-APT/지자체/국방조달/ALIO)
   - 상태 뱃지 (진행중/마감)
   - D-day 카운트다운 (마감일까지 남은 일수)
   - 공사명 (링크 → 원문 상세보기)
   - 발주기관명
   - 지역 (시/군/구)
   - 입찰방식 (일반경쟁, 제한경쟁, 수의계약 등)
   - 추정가 (원 단위 전체 + 약식: 예 "318,091,740원 (3.2억)")
   - 매칭 키워드 태그 (데크, 합성목, 목재데크 등)
   - 첨부파일 링크 (있는 경우)
   - 상세보기 링크

4. **낙찰 결과 그리드**
   - 제목: "최근 낙찰 결과" (N건)
   각 카드:
   - 낙찰업체명
   - 낙찰일
   - 공사명
   - 발주기관 + 지역
   - 낙찰가 (약식)
   - 낙찰률 (%)
   - 예가대비율 (낙찰가/추정가 ×100%)

5. **주요 수주 업체 TOP 10**
   - 랭킹 번호 (#1 ~ #10)
   - 업체명
   - 수주 건수
   - 총 수주 금액

6. **CTA**
   - "입찰 알림을 받아보세요"
   - "데크 관련 새 입찰 공고가 등록되면 카카오톡으로 알려드립니다."
